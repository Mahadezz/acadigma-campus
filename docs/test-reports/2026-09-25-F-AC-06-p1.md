## 1. Scope

**What this Part is.** A school owner or admin opens Settings → Grading (`/app/settings/grade-scale`), adds the Bangladesh GPA 5.00 scale with one tap, and edits its bands. A live preview shows "72 % → A (4.00)". The database refuses a band set with a gap, an overlap, an empty set or grade points that go down. Bands change only through the two owner/admin RPCs. The SQL and TypeScript band/rounding functions are pinned to one parity table.

| #    | Criterion                                                                                                                                | Covered by                                                                                           |
| ---- | ---------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| AC-1 | 72 % → A / 4.00 from one band table (SQL and domain)                                                                                     | `52_grade_scales.sql` (demo row + parity table), `scale.test.ts`, `grading-settings.spec.ts`         |
| AC-2 | `round_half_up(21.5/5, 2) = 4.30`                                                                                                        | `round.test.ts`; SQL rounding parity rows                                                            |
| —    | Every integer 0-100 and each .99 boundary maps to the right letter and grade point; no rounding before banding (79.5 → A, 79.995 → none) | `scale.test.ts` (full sweep); SQL: CASE-oracle sweep of letter and point, every 0.01 step has a band |
| —    | Seed is idempotent                                                                                                                       | `52_grade_scales.sql` A                                                                              |
| —    | Gap / overlap refused                                                                                                                    | `52_grade_scales.sql` C, `scale.test.ts`, `actions.test.ts`                                          |

**Out of scope:** exams, marks, GPA and results (Parts 2-9); creating a second scale; `SCALE_IN_USE` versioning.
