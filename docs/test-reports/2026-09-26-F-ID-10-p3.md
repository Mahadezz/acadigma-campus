## 1. Scope

**What this Part is.** The class hub — `/app/classes/[sectionId]` — the screen the owner's own walkthrough described: "they can just press a class, enter the class; there will be all the handouts, marking, printing, attendance, lesson planner, routine all in one block." This Part ships the four tabs that already have a real page to reuse: **Attendance** (the existing roll call, at basic sizes, with a plain-language `ConfirmSheet` before every save and a 30-second post-save Undo), **Marks** (this section's papers the caller teaches, n/N entered, tap through to the existing marks entry screen — the first time marks are reachable from basic mode), **Students** (this section's roster, Bangla names via `BnEnText`), and **Print** (the report cards of the latest published or computed exam, single and bulk, reusing F-OP-03's existing actions and permissions unchanged). A caller not assigned to a section (and not owner/admin) sees "This class is not on your list," with no student data sent to the browser. Class blocks on the home screen and the "All classes" list now open the hub instead of the roll call directly.

**Acceptance criteria covered** (spec §9):

| ----- | --------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| AC-6  | The hub shows only tabs whose pages exist, no "coming soon" tab             | `CLASS_HUB_TABS` unit test (`packages/domain/src/class-hub/index.test.ts`); `basic-class-hub.spec.ts`                            |
| AC-7  | Attendance Save opens a plain-language confirm sheet; nothing saves first   | `roll-call.test.tsx` ("confirms the plain sentence..."); `basic-class-hub.spec.ts`                                               |

**Out of scope for this Part** (per the builder brief for this Part and the spec's own dependency notes):

- **"Earlier days" (the past-session list)** in the Attendance tab — no repository anywhere in the codebase (F-AC-03 included) lists a section's past sessions yet. The brief's own wording for this Part was "today's roll call inline or one tap to it," which ships.
- **Register/mark-sheet PDF printing** in the Attendance tab — F-OP-03 Part 6 is not merged; the spec's own "if merged, else omit" applies. The Print tab itself (report cards) is unconditional and ships.
- **Routine, Handouts, Lesson plan, Homework tabs** — each is its own future feature Part (F-AC-05, F-TE-05, F-TE-01, F-AC-07), added to `CLASS_HUB_TABS` when it ships, per spec §8's closing note.
- **Part 4 (voice hints)** — untouched by this Part.

**Risk areas:** (1) the hub's own assignment gate (`NOT_ASSIGNED`) had to be strictly separate from, and checked before, every tab's own permission — a bug here would leak another teacher's class data, so it got both a unit test and an e2e journey against real (not fabricated) seed data. (2) `exam_subjects.teacher_id`/`sections.class_teacher_id` are `workspace_members.id`, not `ctx.userId` — the same trap `getMarkSheet` already had to resolve; `listSectionPapers` follows the identical two-query resolve-then-compare shape. (3) the route's own bundle size: reusing `RollCall` (which already pulls in Radix `Sheet`/`Checkbox`) plus a tabbed interface pushed the page over the repo's 250 kB gzipped budget on the first pass — see §6.

## 6. Performance

Measured locally from `pnpm --filter @acadigma/web build` + `node scripts/check-bundle-budget.mjs` (gzip-based, 250 kB budget):

| Route                                                                           | First Load JS (gzipped) | Budget | Result                                 |
| ------------------------------------------------------------------------------- | ----------------------- | ------ | -------------------------------------- |
| `/app/classes/[sectionId]` (this Part)                                          | 244 kB                  | 250 kB | PASS                                   |
| `/app/attendance/[sectionId]` (touched — `basic` prop added, unused by default) | 242 kB                  | 250 kB | PASS (unchanged from before this Part) |
| `/app/classes/all` (unchanged, for comparison)                                  | 194 kB                  | 250 kB | PASS                                   |

**Found and fixed during this Part:** the first version measured **257 kB**, over budget. Root cause: Radix `Tabs` plus all three non-Attendance tab components bundled eagerly into the page. `next/dynamic(() => import(...), { ssr: false })` on Marks/Students/Print barely moved the number on its own (250 kB→257 kB range) — Next still counts a dynamically-imported chunk toward "First Load JS," and hence toward this gzip check, whenever `ssr` is not explicitly disabled. Setting `ssr: false` on all three, plus replacing `@acadigma/ui/components/tabs` with a hand-rolled `role="tablist"` of plain buttons (the tab switcher needed none of Radix's roving-tabindex/orientation logic), brought it to 244 kB. Recorded as D-406 item 7 for the next builder who reaches for `next/dynamic` on a similar problem.

Lighthouse: not run — the existing CI `lighthouse` job only tests unauthenticated pages (`/`, `/login`), same limitation Part 2's report already recorded for `/app/home`.
