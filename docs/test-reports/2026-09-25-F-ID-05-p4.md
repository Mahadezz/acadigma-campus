## 7. Security checks

- The function re-validates every field; a direct RPC call cannot skip Zod's rules (proven by the `VALIDATION` cases, called without the action).
- Rate limit and idempotency run under a per-user advisory lock, so two tabs cannot both pass them.
- An idempotency key belonging to another user returns an error, not their school.
- `grant execute` to `authenticated` only (D-54); anon denied (pgTAP).

### Fixed on the way (Part 3 bugs found by the design reviews)

1. **School type labels overlapped at 360 px** ("English versi|English medium"): the medium toggle group is now one column on phones, two from `sm`, with wrapping labels, a check mark on the selected option (not colour alone) and 44 px targets. Re-checked with the local axe/viewport run above.
2. **Working days were lost on a reload mid-step 2**: the Number[] ↔ String[] mapping was correct; the draft simply only saved on Continue. Working days and timezone now save as soon as they change (debounced 400 ms). `wizard.test.tsx` "saves a day toggle without Continue, and a reload restores it" toggles Sunday, checks the saved draft, re-renders from it and asserts Sunday off / Saturday on; a second test checks the first render writes nothing.
3. **gitleaks flagged the tests' fixed idempotency-key UUID** as `generic-api-key`; that one value is allowlisted in `.gitleaks.toml` with a reason.

### Review fixes (PR #37, security and database review)

- **One door:** a signed-in user could insert a `type='school'` workspace directly through PostgREST and skip the limits. The client INSERT policy and grant are gone; pgTAP asserts the direct insert fails (`permission denied for table workspaces`) in `30_`, `15_` and `16_`. `16_billing_bootstrap_guard.sql` now exercises the same bootstrap triggers under role `authenticated` through `create_school_workspace`; `19_` seeds its schools as `postgres`.
- **EIIN oracle:** all input is validated before the EIIN is tried (pgTAP: taken EIIN + bad year → `INVALID_ACADEMIC_YEAR`); each validated attempt is counted in `createSchool` (pgTAP: an `EIIN_TAKEN` attempt leaves 1 in the bucket; the 31st attempt returns `RATE_LIMITED` and the block persists); a direct `school_profiles.eiin` UPDATE is refused.
- **`created_by` immutable** on both new tables (pgTAP), **require_writable** attached (pgTAP: a read-only school cannot add a grade level), **audit catalogue** rows seeded for both tables (`check-audit-catalog-parity.mjs`: 21 generic tables), **index** for the per-day count.
- **Wizard errors:** every error the create can return has its own copy (en + bn) and a way forward; `IDEMPOTENCY_KEY_REUSED` tells the user the school already exists instead of offering a retry that can only fail (`reviewError` unit tests). The step 2 autosave call moved out of the state updater.
