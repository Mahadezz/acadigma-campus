## 7. Security checks

- The function re-validates every field; a direct RPC call cannot skip Zod's rules (proven by the `VALIDATION` cases, called without the action).
- Rate limit and idempotency run under a per-user advisory lock, so two tabs cannot both pass them.
- An idempotency key belonging to another user returns an error, not their school.
- `grant execute` to `authenticated` only (D-54); anon denied (pgTAP).

## 8. Known issues

1. **Logo step not built** (D-100): needs file uploads and a Settings → Workspace screen first.
2. **The live e2e journey is skip-gated** (OQ-27); the axe/viewport evidence above is from a local preview, not from CI.
3. **`grade_levels.*` and `academic_years.*` are not in `audit_action_catalog`**, so their audit rows default to severity `info` and the viewer has no sentence template for them yet.
4. **No madrasah presets** (OQ-2 open); madrasahs can add custom levels.
5. **Trial restart across schools** (OQ-4) is not blocked here; each school gets its own trial.
6. **Depends on #35**: once `app.tg_require_writable()` merges, `grade_levels` and `academic_years` need its trigger and this migration may need a later timestamp.
