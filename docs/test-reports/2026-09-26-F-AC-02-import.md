## 1. Scope

An owner or admin downloads a bilingual template, uploads a `.xlsx` or `.csv` register, sees a stored preview with every bad row (line, column, what is wrong in plain English or Bangla, what was typed), and imports the valid rows. Each row is admitted by `public.import_student_batch` through `public.admit_student`, so codes, roll numbers, guardians, enrolments, audit and every rule are the quick-admit ones. The report lives in `student_import_batches`, so a reload shows the same preview or result. Limits: 2,000 rows, 1 MB.

## 7. Security checks

Tenant context from `requireWorkspace`; `can("students.import")` then `requireWritable` in both actions; RLS owner/admin on the table; the function re-checks the role; no UPDATE/DELETE grant; every row re-validated by `admit_student`. `.xlsx` is read from a Buffer only (read-excel-file treats a string as a file path). `pnpm audit --audit-level high`: no known vulnerabilities. Report data (DOB, phones) is redacted from the audit trail.

## 8. Known issues

1. **Zip bomb:** a 1 MB `.xlsx` is decompressed in memory by read-excel-file with no decompressed-size cap. Owner/admin only and one file at a time; a cap needs a pre-scan of the zip directory.
2. No rate limit on `previewStudentImport` / `commitStudentImport` (§7 says 20/h and 10/h).
3. Deferred (D-106): "download errors as CSV", per-cell highlight table on desktop, duplicate-student warnings, update-by-code, the queued guardian-invite offer, `validating`/`failed` statuses.
4. The template has no example row (a forgotten example would be imported); the page lists the columns and formats instead.
5. The migration is named `20260925300316_…` by the lead's assignment (real UTC time still sorts before main's `2026092530031x`, and `…300312`–`…300315` belong to other open PRs). If the order check fails after another merge, rename as `check-migrations-order` suggests.
6. `types.generated.ts` was extended by hand for the new table, enum and function; replace it with CI's `types-generated` artifact if the `db` job's types step differs.
