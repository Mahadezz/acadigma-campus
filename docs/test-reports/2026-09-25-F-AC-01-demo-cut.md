## 4. Database (pgTAP)

`32_sections_and_subjects.sql` **28/28**, and every other file passes locally:

- the owner creates Class 6 – A with a class teacher and room; duplicate names (any case) are refused;
- one live section per class teacher per year; archiving frees the teacher;
- a parent or a removed member cannot be a class teacher (`MEMBER_NOT_ELIGIBLE`);
- another school's owner cannot reference this school's grade level or member (composite FK), cannot read or add sections here;
- teacher: reads, cannot insert, update touches nothing; staff read; parent reads nothing;
- subjects: unique name (any case) and code per school, code format, same name fine in another school;
- read-only mode refuses inserts and updates on both tables; `created_by` immutable; anon has no privilege; section inserts are audited.
