## Rules learned this session (now also in `CLAUDE.md`)

1. **A new migration must sort after the newest one on `main`.** `supabase db push` refuses a migration dated before the newest applied one, so an old-dated file breaks the production deploy on merge (#6 had to be re-dated).
2. **Supabase grants `anon`/`authenticated` EXECUTE explicitly** through default privileges; `revoke ... from public` alone does not remove them. Since D-54 the defaults deny, so every new client-callable function needs an explicit `grant`.
3. **Generated types come from CI** (D-55). When the `db` job's type step fails: `gh run download <run-id> -n types-generated -D packages/db/src`, then commit.
4. **After a cloud session force-pushes,** refresh laptop worktrees with `git fetch origin && git switch -C <branch> origin/<branch>`, then `pnpm install --frozen-lockfile` before trusting a local typecheck.
5. **Count RLS-protected rows as `postgres`** (`tests.logout()`) in pgTAP, unless the assertion is specifically about what the caller can see.
6. **Seeded-account Playwright journeys need the `E2E_LIVE_SUPABASE` skip guard** until OQ-27 is done.
7. **A PostgREST RPC is its own transaction.** A helper that sets a transaction-local value over RPC cannot affect a later request (the removed `setCorrelationId`).
